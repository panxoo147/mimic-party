# 🎤 Mimic Party (เวอร์ชันเว็บ, fan-made)

เกมปาร์ตี้เลียนแบบเสียง แรงบันดาลใจจาก [Mimic Party](https://store.steampowered.com/app/5053820/Mimic_Party/) — เล่นหลายคนผ่านเบราว์เซอร์ ผู้เล่นสแกน QR Code เข้าห้องด้วยมือถือ ฟังเสียงต้นฉบับ แล้วเลียนแบบด้วยเสียงตัวเองผ่านไมค์มือถือ ระบบจะให้คะแนนความเหมือนแบบอัตโนมัติ (ดูจากจังหวะ/รูปทรงของเสียง ไม่ได้ดูโทนเสียง)

ทำด้วย Node.js + Express + Socket.IO ไม่ต้อง build อะไรเพิ่ม

## ฟีเจอร์

- เล่นหลายคนพร้อมกัน ผู้เล่นเข้าห้องด้วยการสแกน QR Code จากมือถือ
- โหมด "ดูอย่างเดียว" (observer) สำหรับคนที่อยากดูเฉยๆ ไม่แข่ง
- Host เลือกเสียงได้ 2 ทาง: (1) ไฟล์ในโฟลเดอร์ `assets/sounds` (2) วางลิงก์จาก [myinstants.com](https://www.myinstants.com/en/categories/memes/th/) ให้ระบบดึงมาอัตโนมัติ
- ตั้งจำนวนรอบได้เอง (จะสุ่ม/วนเสียงในคลังที่เลือกไว้ให้ครบจำนวนรอบ)
- แต่ละรอบ: ผู้เล่นฟังเสียงจากมือถือตัวเอง (ใส่หูฟังได้) → เลียนแบบพูดใส่ไมค์ → ระบบเปิดเสียงที่แต่ละคนอัดให้ทุกคนฟังทีละคนพร้อมเฉลยคะแนน → สรุปคะแนนสะสม
- คะแนนคำนวณจากรูปคลื่นพลังเสียง (ความดัง-เบาตามเวลา) เทียบกับต้นฉบับ ไม่สนใจว่าเสียงสูง/ทุ้มต่างกัน

## วิธีติดตั้งและรัน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm start
```

เปิดเทอร์มินัลจะเห็นลิงก์ประมาณนี้:

```
- บนเครื่องนี้: http://localhost:3000/host
- ในวง LAN เดียวกัน: http://192.168.1.23:3000/host
```

**สำคัญ:** ให้เปิดหน้า `/host` (จอสำหรับ Host/ทีวี) ผ่าน **ลิงก์ในวง LAN** (ที่ขึ้นต้นด้วย IP เช่น `192.168.x.x`) ไม่ใช่ `localhost` เพราะผู้เล่นที่สแกน QR จากมือถือจะต้องเข้าถึง IP นั้นได้ (ต้องต่อ WiFi วงเดียวกันกับเครื่อง Host)

### ⚠️ เรื่องสำคัญ: ทำไมต้องมีลิงก์ https ด้วย

เบราว์เซอร์ (Chrome/Safari/Firefox) จะ **ไม่อนุญาตให้เว็บไซต์ขอสิทธิ์ใช้ไมโครโฟน** ถ้าเปิดผ่าน `http://` ธรรมดาบน IP วง LAN (ถือว่าไม่ปลอดภัย) ยกเว้นแค่ `localhost` เท่านั้น เซิร์ฟเวอร์นี้จึงเปิดให้บริการทั้ง HTTP และ HTTPS (ออกใบรับรองเองอัตโนมัติให้ตอนรันครั้งแรก) — หน้า Host จะสร้าง QR Code เป็นลิงก์ **https** ให้อัตโนมัติเมื่อเปิดผ่าน LAN

เมื่อผู้เล่น (ที่เลือกโหมด "เล่น" ไม่ใช่ "ดูอย่างเดียว") สแกน QR แล้วเข้าเว็บ เบราว์เซอร์จะเตือนว่า **ใบรับรองไม่น่าเชื่อถือ (self-signed)** — ให้กด "Advanced"/"รายละเอียดเพิ่มเติม" แล้ว "Proceed anyway"/"ไปที่เว็บไซต์นี้ (ไม่ปลอดภัย)" ได้เลย เป็นเรื่องปกติ เพราะเราออกใบรับรองเองสำหรับเล่นในวงบ้าน ไม่ได้ไปขอจากหน่วยงานกลาง (ผู้เล่นที่เลือก "ดูอย่างเดียว" ไม่ต้องใช้ไมค์ จะเข้าผ่าน http ธรรมดาก็ได้)

## การเล่นนอกบ้าน / ให้เพื่อนที่ไม่ได้อยู่ WiFi เดียวกันเข้าร่วม

หน้า Host มีช่อง **"ลิงก์สำหรับเล่นนอกบ้าน"** ให้กรอก URL สาธารณะแล้วกด "ใช้ลิงก์นี้" ระบบจะสร้าง QR Code ใหม่จากลิงก์นั้นให้ทันที วิธีหา URL สาธารณะทำได้หลายแบบ:

### วิธีที่ 1: เปิด tunnel ชั่วคราวด้วย Cloudflare Tunnel (ฟรี ไม่ต้องสมัคร)

```bash
npx cloudflared tunnel --url http://localhost:3000
```

จะได้ลิงก์ประมาณ `https://xxxx-xxxx.trycloudflare.com` เอาไปวางในช่อง "ลิงก์สำหรับเล่นนอกบ้าน" บนหน้า Host

### วิธีที่ 2: ngrok

```bash
ngrok http 3000
```

จะได้ลิงก์ `https://xxxx.ngrok-free.app` เอาไปวางในช่องเดียวกัน

### วิธีที่ 3: Deploy ขึ้นเซิร์ฟเวอร์จริง (ถาวร)

โปรเจกต์นี้เป็น Node.js app มาตรฐาน สามารถ deploy ขึ้นบริการอย่าง Render, Railway, Fly.io ได้ โดย:

- Build command: `npm install`
- Start command: `npm start`
- ตั้งค่า persistent disk/volume ให้ครอบคลุมโฟลเดอร์ `library_cache/`, `data/`, `uploads/` ถ้าอยากให้คลังเสียงที่ดึงจาก myinstants ไม่หายเวลา redeploy (ถ้าไม่ตั้งก็ไม่เป็นไร แค่ต้องดึงเสียงใหม่หลัง deploy รอบใหม่)
- เปิดหน้า `/host` ผ่านโดเมนที่ deploy ได้เลย ไม่ต้องกรอกช่อง "ลิงก์สำหรับเล่นนอกบ้าน" เพราะ QR จะใช้ลิงก์ของโดเมนนั้นให้อัตโนมัติอยู่แล้ว

> หมายเหตุ: เมื่อเล่นข้ามเน็ตสาธารณะ ควรมีการ deploy จริงหรือใช้ tunnel ที่เสถียร เพราะถ้า Host ปิดคอมหรือขาดเน็ต เกมจะหยุดทันที (สถานะเกมเก็บในหน่วยความจำของเซิร์ฟเวอร์)

## วิธีเพิ่มเสียงเข้าคลัง

**จากไฟล์ในเครื่อง:** ก็อปไฟล์เสียง (.mp3, .wav, .ogg, .m4a) วางในโฟลเดอร์ `assets/sounds/` แล้วกด "🔄 รีเฟรชคลังเสียง" ที่หน้า Host

**จาก myinstants.com:** เปิด https://www.myinstants.com/en/categories/memes/th/ (หรือหมวดอื่น) หาเสียงที่ชอบ เปิดหน้าเสียงนั้น (คลิกเข้าไปที่ชื่อเสียง) แล้วคัดลอก URL มาวางในช่อง "🔗 จาก myinstants.com" บนหน้า Host กด "ดึงเสียง" ระบบจะดาวน์โหลดมาเก็บไว้ใน `library_cache/sounds/` ให้อัตโนมัติ

## หลักการให้คะแนน (โดยย่อ)

ระบบเทียบเสียง 3 มิติ ถ่วงน้ำหนักรวมกันเป็นคะแนน 0-100:

1. **รูปทรงพลังเสียง (shape)** — ถอดรหัสเสียงด้วย ffmpeg แล้วคำนวณ "เส้นพลังเสียงตามเวลา" (RMS envelope) ของทั้งต้นฉบับและเสียงที่อัด normalize ให้เทียบกันได้ไม่ว่าเสียงจะดัง/เบาแค่ไหน แล้วเทียบรูปทรง (correlation)
2. **จังหวะ (rhythm)** — นับจำนวน "จุดเน้นเสียง" (onset) เช่น พูดครั้งเดียวหรือสามครั้ง แล้วเทียบว่าตรงกันไหม
3. **ทำนอง/ระดับเสียงสัมพัทธ์ (melody)** — ตรวจจับระดับเสียง (pitch) ต่อช่วงเวลาด้วยวิธี autocorrelation แล้วแปลงเป็น "ระดับเสียงเทียบกับค่าเฉลี่ยของตัวเอง" (ไม่สนใจว่าใครเสียงสูง/ต่ำกว่าใคร ดูแค่ว่าเสียงขึ้น-ลงเป็นรูปทรงเดียวกันไหม) น้ำหนักของมิตินี้จะถูกปรับอัตโนมัติตาม "ต้นฉบับมีทำนองชัดเจนแค่ไหน" — ถ้าเป็นเสียงเอฟเฟกต์ที่ไม่มีระดับเสียงชัดเจน ระบบจะไม่บังคับเทียบมิตินี้ (กลับไปดู shape+rhythm เป็นหลักเหมือนเดิม)

มิติที่ 3 คือส่วนสำคัญที่กันไม่ให้แค่ "พูดมั่วๆ" ให้ระดับเสียงดัง-เบาตรงจังหวะเฉยๆ ได้คะแนนเต็ม เพราะถ้าต้นฉบับมีทำนองชัดเจน การเลียนแบบที่ไม่ได้ใส่ใจระดับเสียงขึ้น-ลงจริงๆ จะโดนหักคะแนนในมิตินี้ทันที ต่อให้จังหวะความดัง-เบาจะตรงเป๊ะก็ตาม

คะแนนนี้เป็นการประมาณแบบง่าย ไม่ได้แม่นยำเท่าอัลกอริทึมของเกมต้นฉบับ แต่ให้ผลที่สมเหตุสมผลและสนุกพอสำหรับเล่นกันเองในกลุ่มเพื่อน ถ้าเล่นแล้วรู้สึกว่าคะแนนยังหลอกง่ายไป หรือหักคะแนนคนที่เลียนแบบดีแล้วเกินไป บอกได้เลย ปรับน้ำหนัก/threshold ในไฟล์ `server/audio.js` ได้อีก

## โครงสร้างโปรเจกต์

```
mimic-party/
  server/
    index.js         entrypoint + REST API + Socket.IO + ตรรกะเกม
    rooms.js          จัดการห้องและผู้เล่น (in-memory)
    soundLibrary.js    จัดการคลังเสียง (ไฟล์ในเครื่อง + myinstants)
    audio.js           ถอดเสียงด้วย ffmpeg + คำนวณคะแนนความเหมือน
  public/
    host.html/js       หน้าจอ Host (ทีวี/คอมกลาง)
    play.html/js       หน้าจอผู้เล่น/ผู้ชม (มือถือ)
    css/style.css
  assets/sounds/        ไฟล์เสียงที่เตรียมไว้เอง
  library_cache/sounds/ ไฟล์เสียงที่ดึงจาก myinstants (auto-generated)
  data/library.json     ข้อมูล metadata ของคลังเสียง (auto-generated)
  uploads/takes/         ไฟล์เสียงที่ผู้เล่นอัดส่งมาในแต่ละเกม (auto-generated)
```

## ข้อจำกัดที่รู้อยู่แล้ว (v1)

- สถานะเกมเก็บในหน่วยความจำ — รีสตาร์ทเซิร์ฟเวอร์แล้วห้อง/คะแนนจะหายหมด
- ยังไม่มีระบบไอเทมกวนๆ/sabotage แบบเกมต้นฉบับ (ทำแบบเรียบง่ายก่อนตามที่ตกลงกันไว้)
- ต้องใช้เบราว์เซอร์ที่รองรับ `getUserMedia`/`MediaRecorder` (Chrome/Safari/Edge เวอร์ชันใหม่ๆ ใช้ได้หมด) และควรใช้ผ่าน HTTPS หรือ localhost/LAN ตอน dev (ข้อกำหนดของเบราว์เซอร์เรื่องสิทธิ์ไมค์)
